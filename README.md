# PHANTOM SHIFT

怪盗が警備ロボを欺き宝石を奪って脱出する、Phaser 3製のステルス・プラットフォーマーです。

## ローカル起動方法

```bash
# リポジトリ直下で簡易サーバを起動
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開くと起動します。

## GitHub Pages デプロイ方法

1. 本リポジトリを GitHub に push
2. GitHub Pages の設定で `main` ブランチのルートを公開対象に指定
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` へアクセス

## ステージJSONについて

レベルデータは `levels/*.json` で管理しています。

必須項目:

- `meta`: ステージIDと言語名
- `tileSize`: タイルサイズ（px）
- `map`: 0=空, 1=床, 2=壁, 3=トゲ
- `zones.shadow`: 暗がり矩形
- `entities`: スポーン、宝石、ゴール、チェックポイント、ガード

新しいステージを追加する場合は `levels/` に JSON を追加し、
シーン側で読み込むステージIDを登録してください。

## 操作

- PC: A/D または ←/→ で移動、Space でジャンプ、S/↓ でしゃがみ、Esc でポーズ、R でリトライ
- スマホ: 左側のタッチUIで移動、右側でジャンプ/しゃがみ/ポーズ

## 保存データ

`localStorage` に `phantomshift_save_v1` で保存されます。

## サウンド

WebAudio を使用した簡易トーンを生成しています。
BGM/SEは設定画面で音量を調整できます。

## 素材差し替え

- 画像や音声素材は `assets/` に追加し、シーン内の生成/読み込みを差し替えてください。
- フリー素材を使用する場合は `CREDITS.md` に出典を追記してください。
